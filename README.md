# vortexpay-api
A robust financial orchestration and subscription management engine built with Java 21 and Spring Boot 3. This API handles complex billing lifecycles, payment processing simulations, and scheduled tasks for recurring revenue management. Designed with scalability in mind, it features a modular architecture ready for high-concurrency environments.
